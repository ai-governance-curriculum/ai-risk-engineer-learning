# Labs for mod-112-cross-functional-ai-risk-program-and-communication (Cross-Functional AI Risk Programme and Communication)

Three 45-minute guided drills. Each builds one atomic artefact-shape authoring skill the exercises assume, on a fixed running system (`HelpDesk`, a customer-support RAG assistant for a mid-size B2B SaaS company; in-house fine-tune `helpdesk-finetune` v1.4.0 on the vendor-hosted base `FoundationCo-LLM-3.5` v3.5.2; EU-and-US deployment on a US-bank sponsoring organisation; the same `HelpDesk` carried through the mod-109, mod-110, and mod-111 labs with the fine-tune bumped to v1.4.0 to match the current chapter-01 and chapter-02 running examples). The labs do not duplicate the module's exercises — the exercises run against the reader's own primary running system (programme charter for the whole team in exercise 01; full three-decision council packet with one-pager / decision log / minutes in exercise 02; full three-card set with all seven risk-slice components in exercise 03; full T2 → T3 tier-promotion block with escalation contract in exercise 04; full crosswalk across ten-plus artefacts with gap register and coverage summary in exercise 05; and the three-year personal certifications plan in exercise 06). The labs drill the atomic artefact shapes those exercises rely on against the fixed `HelpDesk` system with fabricated-but-plausible identifiers and metadata, using deliberately contrasting scenarios so the lab artefacts and the exercise artefacts are not confused.

- [`lab-01-decision-slide-seven-field-authoring-drill.md`](lab-01-decision-slide-seven-field-authoring-drill.md) — 45 minutes. Author the chapter-02 decision-slide seven-field shape end-to-end for two deliberately contrasting decisions on `HelpDesk` for the mock 2026-09-24 2026-Q3 council: decision D-01 (T2 → T3 promotion, shaped to force the "monitored ramp with mechanically enforceable rollback" shape — recommendation B over the straight-promotion option A, with five pre-registered rollback triggers each specifying metric, threshold, and duration guard) and decision D-02 (above-appetite acceptance on `tenant_tier` fairness parity, 90-day window, shaped to force the "acceptance expires on a date, not on 'we will revisit'" shape plus the chapter-02 silent-above-appetite forced-slide rule). Includes the seven fields in order (decision requested; scope; evidence pointers with artefact IDs + versions + hashes; options and recommendation with ≤ 3 lines of rationale; residual-risk claim with named monitors and thresholds; escalation dependency; rollback / reversibility with mechanical triggers) and a per-slide readiness checklist against the chapter-02 acceptance tests. Chapter 02 skill feeding exercise 02's three-decision council packet.
- [`lab-02-model-card-residual-risk-section-authoring-drill.md`](lab-02-model-card-residual-risk-section-authoring-drill.md) — 45 minutes. Author the chapter-03 `Residual Risk` section (the three-part shape: level on named cohort; monitors with named thresholds; pre-registered invalidation triggers) and the chapter-03 `Uses — Out-of-Scope Use` section (specific statutory exclusions E-01 — no hiring/credit/medical/legal/tax decisions, no minors — and the HIPAA-adjacent-flow exclusion E-02 — no outbound tool call, no RAG retrieval, no response generation on PHI-carrying flows) for `HelpDesk` in the Hugging Face model-card schema. Includes the YAML metadata front-matter with register row back-pointers (`HR-CS-INJ-01`, `HR-CS-PII-04`, `HR-CS-FAIR-08`, `HR-CS-DRIFT-02`), the aggregate residual claim (Medium-low on Cohort C-01 with `HR-CS-FAIR-08` at Medium for the 90-day above-appetite window), the four named monitors (`SC-HD-INJ-01` injection-defeat 30-day rolling; `SC-HD-PII-01` PII-egress per-call hard-floor zero; `SC-HD-FAIR-01` per-slice parity 7-day rolling +/-5-point band; `SC-HD-DRIFT-01` embedding-drift daily 0-0.12 band), the seven pre-registered invalidation triggers (each with metric + threshold + duration + mitigated-state), the "what this residual claim does *not* cover" scope-limit subsection (Cohort C-02 HIPAA-adjacent flows; non-English dialects; minors), and the readiness checklist against chapter 03's acceptance criteria. Chapter 03 skill feeding exercise 03's full three-card set.
- [`lab-03-crosswalk-row-and-gap-disposition-drill.md`](lab-03-crosswalk-row-and-gap-disposition-drill.md) — 45 minutes. Author the chapter-05 crosswalk row shape for `ART-HD-GRD-Q3-01` (the guardrail-effectiveness report that chapter 05 §"The 'one artefact, many standards' pattern — worked" worked explicitly — filing against MEASURE-2.5 / MEASURE-2.6 / MEASURE-2.7 / MANAGE-2.2 / ISO 42001 A.6.2.4 / EU AI Act Article 15) plus ten supporting rows covering the artefact set the HelpDesk programme has at Q3 2026; the coverage summary counting filled / waived / escalated per framework family; and the three-disposition gap register with one entry per disposition class — G-01 MEASURE-4.1 (gathering feedback; disposition `fill` with owner / target date / back-pointer); G-02 EU AI Act Article 14 (human oversight; disposition `waive with rationale` — the waive is on the sibling-artefact requirement not on the article itself, which is filled on two existing artefacts; with sign-off role / date / re-evaluation condition); G-03 RMF MANAGE release-assurance evidence-bundle packaging (disposition `escalate` to `ai-evaluation-engineer` L35 with mod-101 ch 06 contract cited, evidence bundle for the hand-off enumerated, and L25's continuing citation-maintenance responsibility explicit). Includes the maintenance discipline (monthly hash check; per-framework-revision; per-system-change; per-audit regeneration; CI-check wiring for `check-hash.sh`, `check-citation.sh`, `check-gap-disposition.sh`). Chapter 05 skill feeding exercise 05's full programme-scale crosswalk and gap register.

Run the labs in order — they each exercise a distinct artefact shape on the shared `HelpDesk` system, and the artefacts stack: lab 01's decision slides are what the chapter-02 decision log rows record; lab 02's residual-risk section is what the chapter-04 tiering document's rollback triggers project onto the external-facing card; lab 03's crosswalk rows include the decision log, the card, and the tier contract as rows in their own right citing overlapping framework columns. Together the three drills carry the atomic artefact shapes exercises 02, 03, 04, and 05 depend on, so when the exercises run on the reader's own real system the time goes into engineering judgement — which decisions belong at council scope on a real quarterly cadence; which residual claim the real evidence supports with which invalidation triggers; which gaps the real crosswalk surfaces and which disposition each takes — not into inventing the artefact format. Chapter 01's programme-charter shape and chapter 06's certifications-portfolio shape are exercised through the quiz and through exercises 01 and 06 directly rather than through dedicated labs, because the engineering judgement in both chapters is the *content* authored against the reader's real team (or real target employer profile), not an atomic artefact shape — and the programme-level forcing function is covered by the artefact chain the labs already drill (charter → council packet → cards → tiering → crosswalk).
