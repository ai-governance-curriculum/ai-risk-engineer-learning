# Labs for mod-109-continuous-monitoring-and-risk-register-integration (Continuous Monitoring, Post-Market Surveillance, and Risk-Register Integration)

Three 45-minute guided drills. Each builds one atomic output-shape authoring skill the exercises assume, on a fixed running system (`HelpDesk`, a customer-support RAG assistant for a mid-size B2B SaaS company, high-risk under EU AI Act Annex III; FastAPI + LangGraph + LangChain retriever over an internal pgvector store; two production tool calls `escalate_ticket` and `lookup_account`; `tenant_tier` as the per-slice proxy for coverage parity). The labs do not duplicate the module's exercises — the exercises run real tools (whylogs + Evidently + Alibi Detect; mod-108 guardrail events; a reducer that materialises an Article 72 report; a routing dispatcher against PagerDuty / Opsgenie and a real security tracker) against the reader's own running system; the labs drill the output shapes those artefacts rely on against the fixed `HelpDesk` system with fabricated-but-plausible numbers.

- [`lab-01-signal-contract-row-authoring-drill.md`](lab-01-signal-contract-row-authoring-drill.md) — 45 minutes. Author the chapter-01 fifteen-column signal contract end-to-end on `HelpDesk`: the front-matter (system identifier, high-risk classification, contract semantic version, plan version, sign-off routing including the risk-council chair, families-in-scope list and justified scope-outs), one row per signal family with all fifteen columns populated (drift, aggregate quality, per-slice fairness-tagged quality, embedding MMD, two-sided injection firing rate, PII absolute-rule, near-miss weekly, cost anomaly, latency SLO burn — nine rows covering the seven chapter-03 families plus the per-slice sibling and the embedding-drift row), the family coverage table, and the four-section chapter-01 anti-pattern probe (ad-hoc dashboard credited as a monitor; silent Slack-only alert; unpinned threshold; missing deferral clause). Every `signal_semantics` sentence names unit / window / denominator; every threshold cites origin (Siddiqi band / Gretton MMD / SRE workbook burn / absolute harm rule); every `deferral_boundary` cites peer L25 `ai-infra-mlops` and, where applicable, peer L30 `ai-eval-engineer`. Chapter 01-03 skill feeding exercise 01 and the detector exercises (02 and 03) that populate the rows.
- [`lab-02-article-72-section-4-and-article-73-log-drill.md`](lab-02-article-72-section-4-and-article-73-log-drill.md) — 45 minutes. Author the chapter-04 §"The report shape" section 4 (per-signal summary; per-register-row residual movements; per-slice observations with fairness liaison on routing; data-quality issues encountered in monitoring with the L25 pipeline-SLO and L30 judge-calibration seams cited) and the Article 73 wire log for `HelpDesk` over a fabricated Q2 2026 reporting period with pre-pinned tripped-signal counts, residual-state deltas, and an incident register. Includes the five-step Article 73 wire walked end-to-end on a non-serious PII incident (triage → disposition → remediation; elapsed times measured against Article 73 deadline envelopes even when the triage returned non-serious) and the mandatory rehearsal entry on a synthetic S1 (because no real serious S1 fired in the period; chapter 04 §"Anti-patterns" forbids an un-rehearsed wire). The rehearsal's drill-finding feeds back into the signal contract as a chapter-01 routing-block diff. Chapter 04 skill feeding exercise 04's reducer and plan-to-report wire.
- [`lab-03-runbook-and-single-source-of-truth-drill.md`](lab-03-runbook-and-single-source-of-truth-drill.md) — 45 minutes. Author the chapter-05 six-section runbook for `SC-HD-INJ-01` (signal meaning in one line; five-item first-check list within the five-minute triage budget; escalation criteria with DPO + legal + risk-council-chair thresholds; containment options with named tool-call levers and named classifier-version rollback; false-positive recording protocol with the record-mutation-as-propagation-vector rule; back-links to register / contract / dashboard / record store / incident-response playbook / correlation memo) and the five-section controlled-trip drill log that walks a fabricated injection fire through four audience views (on-call page; security ticket; governance-council digest queue entry; incident-candidate queue entry — all keyed to one record identifier), the SSOT verifier assertion report (foreign-key / direct-fields / derived-fields columns per audience; "no discrepancies" close), the on-call acknowledgement + runbook execution trace, the false-positive labelling-queue return with the record mutation driving every downstream recompute (near-miss counter decrement; digest entry flag; security ticket state change; candidate disposition; register-row clear), and the drill-close findings filed as runbook / contract / exercise-05 scope diffs. Chapter 05 skill feeding exercise 05's dispatcher, runbook set, queue, digest reducer, and SSOT verifier.

Run the labs in order — lab 02 reads the signal contract row identifiers from lab 01, and lab 03 reuses the `SC-HD-INJ-01` row and the correlation-sibling note the signal contract established. Together the three drills carry the atomic output-shape authoring skills that exercises 01, 04, and 05 depend on, so when the exercises run on the reader's own running system the time goes into engineering judgement — which register rows need runtime signals, how the reducer stays deterministic, which dispatcher integrations to build — not into inventing the artefact format.
