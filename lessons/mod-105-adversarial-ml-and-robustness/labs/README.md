# Labs for mod-105-adversarial-ml-and-robustness (Adversarial ML and Robustness Engineering)

Three short guided drills. Each builds one atomic skill the exercises assume, on the same running `SupportIntent` example (a fine-tuned intent-classifier head on a customer-support LLM assistant) so the running system does not switch between labs. The labs do not duplicate the module's exercises — the exercises build the production artifacts against the reader's own running system; the labs drill the discipline those artifacts rely on against a fixed toy system with fabricated numbers.

- [`lab-01-cross-tag-row-authoring-drill.md`](lab-01-cross-tag-row-authoring-drill.md) — 45 minutes. Author one cross-tag row per NIST AI 100-2 e2025 category (evasion, poisoning, extraction, inversion, MIA, availability) with the three-axis threat-model rubric filled, MITRE ATLAS and OWASP ML Top 10 overlays as separate columns, every row traced to a harm-model row and a register row, and every scope flag specific (`in-scope-this-module` / `handoff:mod-107` / `handoff:sec-L35`). Chapter 01 skill feeding exercise 01.
- [`lab-02-perturbation-budget-curve-authoring-drill.md`](lab-02-perturbation-budget-curve-authoring-drill.md) — 45 minutes. Turn fabricated FGSM / PGD / C&W numbers on `SupportIntent` into report-shaped output: methodology with the three-axis threat model per attack, attack-success with 95% CIs, the perturbation-budget curve as the primary artifact (not a point), a transferability sub-table in both directions, a defence-delta section under *adaptive* PGD and L2-C&W, and a register-handoff paragraph for `REG-SI-EVASION-01`. Chapter 02 skill feeding exercise 02 and the chapter-05 report shape.
- [`lab-03-defence-measurement-matrix-drill.md`](lab-03-defence-measurement-matrix-drill.md) — 45 minutes. Author the chapter-03 defence-measurement matrix for a BadNets backdoor on `SupportIntent` across a `{0.5%, 1%, 5%, 10%}` poison-rate sweep against activation clustering, spectral-signature detection, and STRIP — every row carrying detection rate *and* clean FPR *and* attack-success-with-defence *and* clean-accuracy delta *and* latency delta, with a named disposition (ships / ships-with-caveat / rejects), monitor specs with thresholds, and the chapter-06 co-owned-control row for each defence. Chapter 03 skill feeding exercise 03 and the chapter-05 register hand-off.

Run them in order — each lab's output is a shape exercise 01 (then 02, then 03) will fill with real decisions on the reader's own running system.
